# SEEM5910 期末项目

## 最终研究报告分工

**先只做完整研究报告，演讲和答辩等报告定稿后再提炼。** 当前四个会话应按最终报告目录分工：

| 顺序 | 报告部分 | 要写清楚的内容 |
| --- | --- | --- |
| **第一部分** | 背景、问题与前人工作 | 问题从哪里来、为什么难、前人怎样解决、为什么还有优化空间 |
| **第二部分** | 网络建模与调度算法 | 怎样想到网络模型、调度器和“路由器”在哪里、具体规则、参数和伪代码 |
| **第三部分** | 实验设计、复现与结果 | 用什么语言、怎样运行、如何公平对比、提升来自哪里、结果说明什么 |
| **第四部分** | 完整迭代过程与结论 | 每轮的观察、思考、尝试、结果和下一步，以及最终贡献与局限 |

这里有两项实质调整：

- **前人工作提前到第一部分**，先解释已有办法和剩余问题，再介绍我们的算法。
- **第四部分专门展示研究过程**：每个迭代和优化方向都保留，重要迭代的标题与关键结论标红，失败和未确认的尝试也如实记录。

伪代码归第二部分，运行步骤归第三部分，参考文献和技术附录最后统一整理。每个会话交付完整连续章节，最后按顺序合并。
