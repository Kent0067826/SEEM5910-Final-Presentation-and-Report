## 最终研究报告分工

**先只做完整研究报告，演讲和答辩等报告定稿后再提炼。** 四个会话各负责一个连续部分，最后按顺序合稿。

### 第一部分 问题与已有算法

从一单机器人取送货讲起，说明任务怎样完成，以及为什么每台车都有路可走，整支车队仍会在共用窄门前变慢。介绍已有算法怎样派单、规划路径和协调避碰，讲清楚它们分别解决了什么，以及共享通道还留下哪些优化空间。

### 第二部分 网络建模与优化思路

沿用同一单任务，从门口拥塞的观察讲起，说明我们为什么想到用计算机网络的视角分析问题。把格子地图简化为由房间节点和门链路组成的扁平网络。用一张图指出中央程序哪里承担类似路由器的选路功能，哪里决定是否接单，哪里协调过门放行。用具体过门过程说明如何把网络中的限量和分批服务改写成机器人可以遵守的规则，按需要补充参数和伪代码。

### 第三部分 关键迭代与实验图解

先通读完整迭代记录，再用时间线、回放或对照图呈现改变判断的关键尝试，包括有启发性的失败。每轮讲清当时看到什么、为什么尝试、改了什么、结果如何，以及它如何影响下一轮。介绍网络算法时，用它实际控制的量和动作来解释。用同条件对照区分整套程序的提升和门控本身的收益，并交代必要的复现条件与步骤。

### 第四部分 结论与现实启示

归纳研究得出的结论，说明方法在哪些条件下有效，现有证据支持到哪里。结合仓库窄通道等具体场景，解释哪些思路可用于现实调度，以及哪些条件还需要进一步验证。

完整逐轮记录继续保留，包括失败和未确认的尝试。关键迭代标题与关键结论按报告约定标红。参考文献和技术附录在合稿时统一整理。
